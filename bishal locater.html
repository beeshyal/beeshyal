⚙️ One-time Firebase setup required
For invite links to work (real-time sync between friends), you need a free Firebase project:
  1. Go to console.firebase.google.com
  2. Click Add project → name it anything → Continue
  3. Go to Build → Realtime Database → Create database
  4. Choose Start in test mode → Enable
  5. Go to Project Settings → Your apps → Add web app
  6. Copy the firebaseConfig values into this file's script
